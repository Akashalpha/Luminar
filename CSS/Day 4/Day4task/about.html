What is CSS?

What is Cascading Style Sheets?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of HTML documents. While HTML defines the structure of a webpage, CSS controls how it looks by styling elements such as text, images, colors, spacing, layouts, and animations. By separating content from presentation, CSS makes websites easier to maintain, faster to load, and more consistent across multiple pages.
