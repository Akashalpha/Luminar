Features of CSS


CSS provides powerful features that help developers create attractive, responsive, and interactive websites.



Selectors

Used to select HTML elements for styling.

Example:

  • Element selector
  • Class selector
  • ID selector

Colors

CSS allows text and backgrounds to use different colors.

Examples:

  • Named colors
  • RGB
  • HEX

Box Model

Every HTML element is considered a box.

It consists of:

  • Content
  • Padding
  • Border
  • Margin


Typography


CSS controls:

  • Font family
  • Font size
  • Font weight
  • Text alignment
  • Line spacing

Flexbox


  • A one-dimensional layout system used to align items in rows or columns.

Grid


  • A two-dimensional layout system used for complex webpage layouts.




Responsive Design


  • Media queries allow webpages to adapt to different screen sizes.

Animations


CSS can animate elements using:

  • Transition
  • Transform
  • Keyframes
